## Codebase Patterns
<!-- Consolidate the most important, REUSABLE learnings here (added by the loop). -->
- Python project managed with `uv`. Run checks via: `uv run pytest -q`, `uv run ruff check .`, `uv run mypy`.
- Project code lives in `src/stromboli/` (src-layout); tests in `tests/`. `pyproject.toml` sets `pythonpath=["src"]` for pytest and `packages=["src/stromboli"]` for hatchling.
- Ruff/mypy are configured to target `src` + `tests` only; `scripts/` (Ralph control-plane) is excluded from ruff via `extend-exclude` — never lint/typecheck the Ralph machinery.
- Config: `stromboli.settings.Settings` (pydantic-settings BaseSettings) with `Field(alias="ENV_VAR")`. Use `load_settings(**overrides)` which wraps `ValidationError` into `MissingSettingsError` naming the missing UPPER_CASE env vars. In tests pass `load_settings(_env_file=None)` and monkeypatch env to avoid picking up a real `.env`.
- `.env` is gitignored (added to root `.gitignore` under "Stromboli project artifacts"); `.env.example` documents every required var.
